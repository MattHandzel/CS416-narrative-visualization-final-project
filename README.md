# Intro
This is a data visualization where all of the data came from me! I collected the data from my Galaxy Watch 5 smartwatch (for health-related metrics like sleep, steps walked, heart rate, etc.), and from my google calendar (to get an idea of how I spend my time). The data source is from another project I worked on and keep up to date, it just extracts data from these sources and then exports them to CSVs, (along with some graphs), I repurposed this data for this project.


### Messaging
The message for this data visualization is the impacts of university life on me. In my visualization, I let the user explore how university life impacted my health, especially during critical periods of time (such as during midterms or finals week), how my health changed during my experimental water fasts, and during life events like my break-up.

### Narrative Structure
The narrative structure of this assignment is an interactive slide-show. This is because the user has control of how they move, but they can only move forward or backwards in time. There is interactive elements because the user can hover over a specific day to get more information about that day, or control + click on multiple days to save aggregate them and save them as cards on the bottom. The user can also navigate with arrow keys or h & l like in Vi

### Visual Structure
The visual structure for the scene is a calendar. This is because the data is time-based, and the data is organized by days. The calendar is a familiar format for the user, so they can easily understand how to navigate the data. The calendar is also a good way to show the passage of time, and how events are related to each other. In addition, there are parts of the calendar that are different colors then the rest. This makes the user curious to investigate and see that these periods of time represent important time periods. The user sees what the time period is called and can look at my health metrics and how living through that time period changed how I spent my time. They can also save the time period for later and see how it compares to other time periods. 

### Scenes
The scenes of my narrative visualization are the months of my freshman year of college. The scenes are ordered by the months of the year, starting with August and ending with May. The scenes are ordered this way because it is the most logical way to show the passage of time. 

### Annotations
For the current month, there might be special events that I want the user to know about and explore more, these events could be things such as times when I went home, midterms and finals, my breakup, or hackathons. These annotations give a description of the event and suggest what to look at in the data. 

### Parameters
The user can navigate between the months of the year, and control+click on a any number of days to aggregate the days and save them for later. The state of the narrative visualization is the current month that the user is looking at. 

### Triggers
The user can press a button (or the arrow keys), to move to the next month, or the previous month. The user can also hover over a specific day and that will trigger a tooltip to get more information about that day. The user can also control+click on any number of days to save them for later.
